# Website demos

The `.mp4` files here are web-sized, muted copies of the original recordings in `Videos/demo`. The matching `.jpg` files are their poster frames. The original recordings are not part of the website.

The player's display name is covered in all published videos except **Friends** (at the owner's request). Music Bio starts after the configuration screen so the Last.fm API key and username are not included; its profile-hover name is covered too. `res/img/demo.png` and `res/img/demo-theme.png` are censored as well.
